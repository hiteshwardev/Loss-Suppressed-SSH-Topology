# Topological and Non-Hermitian Nanophotonic Lattices

This repository contains the complete computational workflow for an independent research project
investigating topological and non-Hermitian effects in nanophotonic lattice systems, with a
specific focus on physically measurable quantities such as the local density of states (LDOS)
and spontaneous emission enhancement (Purcell factor).

The project was carried out as a thesis-equivalent independent research effort outside the
formal curriculum.

---

## Scientific Motivation

Topological photonics has primarily been explored at the level of bandstructure and protected
eigenmodes. However, realistic photonic systems are inherently lossy and disordered, raising
the question of whether topological protection extends to **physically measurable optical
observables**.

This project addresses the following core questions:

- Do topological edge states enhance light–matter interaction in realistic nanophotonic systems?
- How does non-Hermitian loss and gain affect this enhancement?
- To what extent is the enhancement robust against structural disorder?
- Which parameter regimes remain experimentally relevant?

---

## System Overview

The studied system is a one-dimensional SSH-type photonic lattice, modeled using effective
tight-binding Hamiltonians and extended to include non-Hermitian terms representing loss and
gain.

Key features:
- Finite-size lattices with open boundary conditions
- Hermitian and non-Hermitian regimes
- Structural disorder in coupling strengths
- Local probing of optical response at lattice boundaries
